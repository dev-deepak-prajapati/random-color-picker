# 🎨 Random Color Picker

A lightweight, responsive web application built with **Vanilla JavaScript** that generates dynamic color palettes and allows users to copy HEX color codes instantly with a single click.

Hosted Live: [Random Color Picker Preview](https://dev-deepak-prajapati.github.io/random-color-picker/)
---

## ✨ Features

- **Dynamic Color Generation:** Automatically generates 1000 unique random HEX color codes on load.
- **One-Click Copy to Clipboard:** Easily copy any color code directly to your clipboard using the Clipboard API.
- **Visual Feedback:** Instant UI transition on the copy button (shifting from a copy icon to a checkmark) to confirm successful copying.
- **Clean & Responsive UI:** Designed with modern CSS layout principles for seamless viewing across devices.

---

## 🛠️ Tech Stack

- **HTML5:** Semantic document structure and markup.
- **CSS3:** Custom styling, layouts, and responsive design.
- **JavaScript (ES6+):** Dynamic DOM manipulation, random color generation algorithms, event delegation, and asynchronous clipboard handling.
- **FontAwesome:** Scalable vector icons for user actions.

## 🚀 Getting Started

To run this project locally on your machine, follow these simple steps:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/dev-deepak-prajapati/random-color-picker.git
   ```

2. **Navigate into the project directory:**
   ```bash
   cd random-color-picker
   ```

3. **Launch the application:**
   Simply double-click the `index.html` file to open it directly in any modern web browser, or use a local server tool like VS Code's *Live Server* extension.
